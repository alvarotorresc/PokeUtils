# Rediseño de interfaz · plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Llevar la app de un *app shell* de móvil estirado a una interfaz de
escritorio: ancho fluido, tipografía legible en los datos, contraste que pasa
4,5:1 en los dos temas, y tres pantallas rediseñadas —home, Pokédex y ficha—
sin tocar ni una ruta, ni un cálculo, ni un dato.

**Architecture:** El orden de las fases lo dicta que **las 21 rutas comparten
`style.css` (2816 líneas) y el contenedor**, pero solo tres pantallas se
rediseñan. Primero lo que todo hereda (tokens de color, fuentes), después el
contenedor (ancho y breakpoints) con las 21 rutas verificadas de una vez sobre
un estado todavía sin rediseñar —esa es la línea base limpia—, y solo entonces
las tres pantallas, una por fase. El buscador global va el último porque es la
única pieza funcional nueva y la que puede alargarse: hasta que llegue, el
buscador de la home lleva a `#/pokedex` y el rediseño ya está cerrado sin él.

**Tech Stack:** HTML + CSS + módulos ES nativos, **sin build y sin
dependencias** (no hay `package.json` y no se añade). Node ≥ 20 para los
scripts `check-*.mjs`. Fuentes: Press Start 2P (ya) y VT323 (nueva), las dos
desde Google Fonts en la misma petición.

**Spec:** [`docs/superpowers/specs/2026-08-06-redesign-design.md`](../specs/2026-08-06-redesign-design.md)

## Global Constraints

- **No cambia ninguna funcionalidad salvo el buscador global.** Ni una ruta, ni
  un cálculo, ni un dato.
- **No se toca `data/`, ni `scripts/build-*.mjs`, ni los once `check-*.mjs`
  existentes.** Se añade uno nuevo (`check-contrast.mjs`) y otro en la fase 6
  (`check-search.mjs`); modificar cualquiera de los once es señal de que se ha
  roto algo que no tocaba.
- **Sin dependencias nuevas.** No se crea `package.json`. Los scripts usan solo
  módulos de Node (`node:fs/promises`, `node:path`, `node:url`).
- **Contraste mínimo 4,5:1** para todo texto, en los dos temas, sobre las tres
  superficies (`--bg`, `--bg-surface`, `--bg-card`).
- **Sin animaciones fuera de las tres del rediseño**: entrada escalonada,
  flotación del enjambre y hover de sprites. El resto va en su propia pasada.
- **`prefers-reduced-motion: reduce` deja el enjambre quieto** y la entrada sin
  animación.
- **La Pokédex mantiene 2 tarjetas por fila a 360 px.** Es la regresión más
  fácil de colar.
- **Estos números no pueden cambiar** en ninguna fase: `#/pokedex` = 1025
  resultados, `#/pokedex?gen=1&sort=spe` = 151 con Electrode primero, el daño
  compartido en 618-728, `#/egg/ground` = 278, `#/speed?id=6` = 206.
- **Servidor local: `node scripts/serve.mjs 8095`.** Nunca
  `python3 -m http.server`: no manda `Cache-Control` y el navegador sigue
  ejecutando los módulos viejos.
- **Idioma del código y los comentarios:** inglés en `js/` y `style.css`
  (es lo que ya hay); español en los `check-*.mjs` y en los textos de la
  interfaz, que además pasan por `js/i18n.js` en ES y EN.
- **Un commit por tarea**, en conventional commits y sin coautoría.

## Precisión al spec, medida en el navegador

El spec dice que «`main#app` tiene `overflow-y: auto`». En el CSS **no está
escrito** —`grep -n "overflow-y" style.css` no da ni un resultado dentro de
`.main`—, pero el navegador **sí lo aplica**: medido a 1920 px,
`getComputedStyle(main).overflowY` devuelve `auto` con `scrollHeight` 2505
sobre `clientHeight` 818.

La causa es que `.main` declara `overflow-x: hidden`, y **CSS obliga a que un
eje en `hidden` convierta el otro de `visible` a `auto`**. El scroll interno no
lo escribió nadie: lo impuso la especificación. Por eso el arreglo de la tarea
5 es **quitar el `overflow-x: hidden` de `.main`** (que ya está en `html` y
`body`, donde corresponde) además de soltar el `height: 100%`.

## Task 1: El barrido de contraste, antes de tocar un color

Es el único trozo automatizable de la verificación del spec, y por eso se
escribe primero: tiene que **fallar** con los colores de hoy.

**Files:**
- Create: `scripts/check-contrast.mjs`
- Read-only: `style.css`

**Interfaces:**
- Produces: `node scripts/check-contrast.mjs` sale con código 1 si algún token
  usado como `color:` mide < 4,5:1 sobre alguna de las tres superficies en
  alguno de los dos temas. Ninguna tarea posterior puede dejarlo en rojo.

> **[decidido sin preguntar]** El barrido es **estático sobre el CSS**, no en el
> navegador. Un `check-*.mjs` con Playwright exigiría `package.json` y
> `node_modules` en un proyecto que hoy tiene cero dependencias. Se paga con
> dos límites conocidos, que el propio script imprime: no ve los colores
> literales que el JS mete inline (`STAT_COLORS`, los `--type-*` de las
> insignias, ya resueltos aparte con `--stat-up`/`--stat-down`), y asume que
> cualquier texto puede caer sobre cualquiera de las tres superficies, que es
> conservador.

- [ ] **Step 1: Escribir el script**

```js
// Comprueba que ningun token usado como color de texto baje de 4,5:1 sobre las
// tres superficies, en los dos temas. Es el unico trozo automatizable de la
// verificacion del redisenio: el resto es manual, ancho por ancho.
//
// Limites conocidos, a proposito:
//   - No ve colores literales inline desde JS (STAT_COLORS, los --type-*).
//     Esos ya se resolvieron aparte con --stat-up/--stat-down y con el punto
//     de color del EV yield.
//   - Asume que cualquier texto puede caer sobre cualquiera de las tres
//     superficies. Es conservador: prefiere un falso positivo a un texto gris
//     sobre gris en produccion.
//
// Run with: node scripts/check-contrast.mjs
import { readFile } from 'node:fs/promises';

// Los tokens salen de style.css, pero el uso se busca tambien en los ocho JS
// que meten color inline: si solo se mirase el CSS, un var(--text-dim) olvidado
// en items.js dejaria el barrido en verde.
const INLINE = ['natures', 'moves', 'abilities', 'items', 'calc-capture',
  'calc-ivev', 'calc-damage', 'pokedex-detail'];

const css = await readFile(new URL('../style.css', import.meta.url), 'utf8');
const inline = (await Promise.all(INLINE.map(name =>
  readFile(new URL(`../js/${name}.js`, import.meta.url), 'utf8')))).join('\n');
const all = css + '\n' + inline;

const MIN = 4.5;
const SURFACES = ['--bg', '--bg-surface', '--bg-card'];

// Tokens que no son texto aunque aparezcan en una declaracion color:, y por que.
const NOT_TEXT = new Set([
  '--on-accent',   // tinta sobre un relleno --accent, que mide 12,48:1
  '--bg',          // texto del color del fondo: iconos y trucos de recorte
  '--bg-surface',
  '--bg-card',
]);

// Excepciones medidas y aceptadas. Cada una lleva su motivo: sin motivo, no
// entra. Se imprimen como "anotado", no como ok.
const ALLOW = {
  '--text-muted@dark@--bg-card': 'Mide 4,41 (a 0,09 del minimo). Subirlo cambia el tono de todas las descripciones de la app para ganar una centesima. 2026-08-06.',
};

function parseBlock(selector) {
  const at = css.indexOf(selector);
  if (at === -1) throw new Error(`No encuentro el bloque ${selector} en style.css`);
  const body = css.slice(css.indexOf('{', at) + 1, css.indexOf('}', at));
  const tokens = {};
  for (const [, name, value] of body.matchAll(/(--[\w-]+)\s*:\s*([^;]+);/g)) {
    tokens[name] = value.trim();
  }
  return tokens;
}

// El tema claro solo redefine parte de los tokens: hereda el resto de :root.
const dark = parseBlock(':root {');
const light = { ...dark, ...parseBlock('.light {') };

function rgb(value) {
  const hex = value.trim();
  if (!/^#[0-9a-f]{6}$/i.test(hex)) return null; // rgba() y gradientes no son texto
  return [1, 3, 5].map(i => parseInt(hex.slice(i, i + 2), 16) / 255);
}

function luminance(value) {
  const parts = rgb(value);
  if (!parts) return null;
  const [r, g, b] = parts.map(c => (c <= 0.03928 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4));
  return 0.2126 * r + 0.7152 * g + 0.0722 * b;
}

function ratio(fg, bg) {
  const a = luminance(fg);
  const b = luminance(bg);
  if (a === null || b === null) return null;
  const [hi, lo] = a > b ? [a, b] : [b, a];
  return (hi + 0.05) / (lo + 0.05);
}

// Todo token que el CSS use como color de texto, incluida la forma abreviada
// dentro de una declaracion multiple.
const used = new Set();
for (const [, token] of all.matchAll(/color\s*:\s*var\((--[\w-]+)\)/g)) {
  if (!NOT_TEXT.has(token)) used.add(token);
}

let failed = 0;
let annotated = 0;

console.log(`\nTokens usados como color de texto: ${used.size}\n`);

for (const [themeName, theme] of [['dark', dark], ['light', light]]) {
  for (const token of [...used].sort()) {
    const value = theme[token];
    if (value === undefined) {
      console.log(`  FAIL ${token} no existe en el tema ${themeName}`);
      failed++;
      continue;
    }
    for (const surface of SURFACES) {
      const r = ratio(value, theme[surface]);
      if (r === null) continue; // no es un hex solido: no se puede medir
      const key = `${token}@${themeName}@${surface}`;
      const label = `${token} ${value} sobre ${surface} (${themeName})`;
      if (r >= MIN) {
        console.log(`  ok   ${label}: ${r.toFixed(2)}`);
      } else if (ALLOW[key]) {
        console.log(`  nota ${label}: ${r.toFixed(2)} — ${ALLOW[key]}`);
        annotated++;
      } else {
        console.log(`  FAIL ${label}: ${r.toFixed(2)} (minimo ${MIN})`);
        failed++;
      }
    }
  }
}

console.log(`\n${failed ? `${failed} por debajo de ${MIN}:1` : 'Todo pasa 4,5:1'}` +
  `${annotated ? ` · ${annotated} anotados a proposito` : ''}\n`);
process.exit(failed ? 1 : 0);
```

- [ ] **Step 3: Escribir el índice**

```js
// ===== INDICE DEL BUSCADOR GLOBAL =====
//
// Cruza los cuatro dominios que hoy solo se buscan por separado. Sin fetch a
// proposito: recibe los datasets ya cargados, y por eso un check-*.mjs puede
// importarlo con readFile igual que hace check-counter con threats.js.
//
// El orden lo decide la puntuacion, no el dominio: buscar "surf" tiene que dar
// el movimiento aunque los Pokemon vayan antes en el objeto.

// Sin acentos y en minusculas: "Pokemon" y "Pokemon" tienen que empatar.
// \p{M} y no un rango de marcas diacriticas escrito a mano: con los caracteres
// combinantes literales en el fuente, cualquier viaje por un editor que
// normalice el fichero deja de coincidir sin dar ningun error.
const norm = s => (s || '').toLowerCase().normalize('NFD').replace(/\p{M}/gu, '');

// Exacto 100, empieza por 60, contiene 30. La diferencia entre exacto y empieza
// tiene que ser mayor que cualquier desempate por longitud, o "fire" lo gana
// "Fire Blast" por ser mas corto que "Fireball".
function score(name, term) {
  const n = norm(name);
  if (!n) return 0;
  if (n === term) return 100;
  if (n.startsWith(term)) return 60 - Math.min(n.length, 30) / 100;
  if (n.includes(term)) return 30 - Math.min(n.length, 30) / 100;
  return 0;
}

// Cada dominio dice de donde saca nombre y ruta. Anadir uno es una entrada mas.
const SOURCES = [
  { key: 'pokemon', kind: 'pokemon',
    names: p => [p.nameEs, p.name, p.nameEn],
    route: p => `#/pokedex/${p.id}`,
    id: p => p.id },
  { key: 'moves', kind: 'move',
    names: m => [m.nameEs, m.name, m.nameEn],
    route: m => `#/moves/${m.id}`,
    id: m => m.id },
  { key: 'abilities', kind: 'ability',
    names: a => [a.nameEs, a.name, a.nameEn],
    route: a => `#/abilities/${encodeURIComponent(a.nameEn || a.name)}`,
    id: a => a.id },
  { key: 'items', kind: 'item',
    names: i => [i.nameEs, i.name, i.nameEn],
    route: i => `#/items?q=${encodeURIComponent(i.name)}`,
    id: i => i.id },
];

export function searchAll(datasets, term, limit = 8) {
  const q = norm(term).trim();
  if (q.length < 2) return [];

  const hits = [];
  for (const source of SOURCES) {
    const rows = datasets[source.key];
    if (!Array.isArray(rows)) continue; // dataset todavia sin cargar
    for (const row of rows) {
      let best = 0;
      let label = '';
      for (const name of source.names(row)) {
        const s = score(name, q);
        if (s > best) { best = s; label = name; }
      }
      if (best > 0) hits.push({ kind: source.kind, id: source.id(row), name: label, route: source.route(row), score: best });
    }
  }

  // Desempate por id para que el orden sea estable entre pulsaciones.
  return hits.sort((a, b) => b.score - a.score || a.id - b.id).slice(0, limit);
}
```

- [ ] **Step 1: El componente**

```js
// ===== BUSCADOR GLOBAL =====
//
// Hasta ahora cada pagina tenia su buscador y ninguno cruzaba dominios. Este
// busca Pokemon, movimientos, habilidades y objetos a la vez.
//
// La carga es perezosa por peso: los cuatro datasets son ~1,5 MB y la home no
// puede pagarlos por si acaso. pokemon.json llega al enfocar y los otros tres
// al primer caracter. loadDataset ya memoiza: pedirlos dos veces no cuesta.
import { searchAll } from './search-index.js';
import { fetchPokemonList, fetchMoves, fetchAbilities, fetchItems } from './api.js';

const KIND_LABEL = { pokemon: 'POKEMON', move: 'MOV', ability: 'HAB', item: 'OBJ' };

export function attachGlobalSearch(input) {
  const panel = document.createElement('div');
  panel.className = 'gs-panel';
  panel.hidden = true;
  input.closest('.swarm-search').after(panel);

  const datasets = {};
  let cursor = -1;
  let timer;

  async function loadPokemon() {
    if (!datasets.pokemon) datasets.pokemon = await fetchPokemonList();
  }

  async function loadRest() {
    if (datasets.moves) return;
    const [moves, abilities, items] = await Promise.all([fetchMoves(), fetchAbilities(), fetchItems()]);
    Object.assign(datasets, { moves, abilities, items });
  }

  function draw(results) {
    cursor = -1;
    panel.hidden = results.length === 0;
    panel.innerHTML = results.map((r, i) => `
      <a class="gs-row" href="${r.route}" data-i="${i}">
        <span class="gs-kind">${KIND_LABEL[r.kind]}</span>
        <span class="gs-name">${r.name}</span>
      </a>`).join('');
  }

  async function run() {
    const term = input.value.trim();
    if (term.length < 2) { draw([]); return; }
    // Dibuja con lo que haya y vuelve a dibujar cuando lleguen los demas: a
    // 1,5 MB, esperar a los cuatro deja el desplegable en blanco varios cientos
    // de milisegundos sobre una conexion normal.
    await loadPokemon();
    draw(searchAll(datasets, term, 8));
    await loadRest();
    if (input.value.trim() === term) draw(searchAll(datasets, term, 8));
  }

  input.addEventListener('focus', loadPokemon, { once: true });

  input.addEventListener('input', () => {
    clearTimeout(timer);
    timer = setTimeout(run, 160);
  });

  input.addEventListener('keydown', e => {
    const rows = [...panel.querySelectorAll('.gs-row')];
    if (e.key === 'ArrowDown' || e.key === 'ArrowUp') {
      e.preventDefault();
      cursor = (cursor + (e.key === 'ArrowDown' ? 1 : -1) + rows.length) % (rows.length || 1);
      rows.forEach((row, i) => row.classList.toggle('on', i === cursor));
    } else if (e.key === 'Enter') {
      // Sin nada marcado, Enter sigue llevando a la Pokedex con el termino.
      const term = input.value.trim();
      location.hash = rows[cursor]?.getAttribute('href')?.slice(1)
        || (term ? `/pokedex?q=${encodeURIComponent(term)}` : '/pokedex');
      panel.hidden = true;
    } else if (e.key === 'Escape') {
      panel.hidden = true;
    }
  });

  // En blur diferido: sin el retraso, el blur cierra el panel antes de que el
  // clic en una fila llegue a registrarse.
  input.addEventListener('blur', () => setTimeout(() => { panel.hidden = true; }, 150));
}
```
